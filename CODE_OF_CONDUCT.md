# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests and discussions. Harassment, insults, personal
attacks and discrimination of any kind are not accepted. Disagree with ideas, not people.

## Reporting

If someone behaves in a way that breaks this code, contact the maintainer,
[@neerajdad123-byte](https://github.com/neerajdad123-byte), privately through a
[private report](https://github.com/neerajdad123-byte/moe/security/advisories/new) (mark it as a conduct report),
instead of replying in public. Reports are handled confidentially.

The maintainer may edit or remove comments, commits, code and issues that break this code, and may block people who
repeatedly or seriously break it.
